# RE Inmobiliaria · demo

Versión de demostración de la nueva página web de RE Inmobiliaria S.A.S.

- Los inmuebles vienen de SIMI y se actualizan cada hora (pestaña Actions →
  "Actualizar inmuebles de SIMI"; el botón "Run workflow" actualiza ya).
- El panel interno usa datos de ejemplo guardados solo en el navegador.
- Los formularios de la demo no envían nada.

Este repositorio se genera desde el proyecto privado: no se edita aquí.
